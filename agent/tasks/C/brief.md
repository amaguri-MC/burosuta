# 指示書 C-<id>: オリジナルキャラのモデル1体（担当キャラは起動時のメッセージで指定）
先に agent/tasks/COMMON.md と tools/MODEL_FORMAT.md を読む。
目的: ブロスタ風バトルロイヤルMODのキャラ1体の 3Dモデル（JSON）とテクスチャ（PNG）を作る。性能はブロスタ準拠だが、**見た目は完全オリジナル**。実在のゲームのキャラに似せない（色・髪型・服・持ち物の組み合わせで既存キャラを連想させない）。
担当範囲: src/client/resources/assets/brawl/models/brawler/<id>.json, src/client/resources/assets/brawl/textures/entity/brawler/<id>.png, agent/preview/C/<id>/**（生成スクリプトもここ）
画風（ユーザーの好み）:
- デフォルメ: 大きい頭（体の1.3〜1.6倍幅）・大きな目・短い胴と脚。全高 26〜34px。シルエットだけで誰か分かる特徴を1つ以上（帽子・角・背負い物など）
- マットなトゥーン: 陰影は色に焼き込む（上が明るく下が暗い2〜3段）。縁取りは黒一色にせず、隣の色を暗くした色相で
- 1面ずつ手で描いたドット絵らしさ（ベタ塗り1色の面を作らない。服のしわ・縫い目・ハイライト）
- 武器は weapon ボーンに作り込む（右手に持つ。正面から形が分かる大きさ）
作業: Python で JSON とテクスチャを生成 → `python3 tools/model_preview.py <json> <png> agent/preview/C/<id>/preview.png` → 自分で Read して直す、を納得まで繰り返す（最低3回は見直す）
合格基準:
- [ ] プレビューの6枚すべてで破綻なし（面の抜け・UVずれ・浮いた部品・めり込みなし。腕は肩、脚は股から振れている）
- [ ] 正面で顔が魅力的に見え、斜め上から見てもキャラが分かる
- [ ] model_preview.py の警告なし（頭身比の警告も消す）
- [ ] 既存ゲームキャラを連想させない
返答: 「完了 / 成果物 / 不確かな点」を3行以内
